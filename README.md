# 元件网络 · 玩家功能指南

> 本模块为网络插件提供元件存储、自动装配、线路传输三大类内容。以下全部物品在粘液指南「网络拓展」分类中获取。

## 一、存储系统

### 存储元件（15 档）
网络的标准仓库。每种物品独占一格，档位决定每格上限（64 → 140.7T）。
- 右键：查看元件内容、搜索、升级格数（消耗对应档位的量子存储）
- 元件界面内 Shift+左键物品：设为保留位（取光也占格）；Shift+右键：开启满载清空
- 放入元件驱动器后接入网络，全网络可存取

### 无限元件
每格数量无限、格数无限，无需升级。右键查看内容。

### 虚空元件
网络装不下的物品，命中过滤器即销毁，防止产线堵死。
- 右键：设置过滤器，最多 9 类
- 不能放入末影驱动器

### 元件驱动器
插入存储元件（共 9 槽），元件里的物品即网络库存。必须接入有网络监视器的网络。
- 右键：打开驱动器
- 空手右键元件槽：直接查看该元件内容
- 首次放置自动绑定主人；白名单界面可添加共享玩家（最多 14 人）

### 末影驱动器
绑定频道后，同频道的所有末影驱动器共享元件。
- 持频道配置器右键：绑定（无频道自动新建）
- 潜行右键：复制频道；潜行右键空气：清空配置器
- 点中央槽位：解绑

### 频道配置器
末影驱动器的频道钥匙，绑定/复制/清空见上。

### 驱动器监视器
总览同网络全部元件驱动器。
- 左键：远程打开该驱动器
- 右键：地面箭头引路
- Shift+左键：命名；Shift+右键：清除命名
- 放大镜按钮：按名称/坐标搜索，支持拼音

## 二、自动装配

### 装配卡
配方的载体。到装配工坊写入配方后，插入装配驱动器即开始生产。

### 装配工坊
给空白装配卡写入配方。
- 放入装配卡和材料，左键编码 1 次；Shift+左键最多 64 次
- 每次编码消耗 2000J 电力，材料真实扣除
- 放入已编码卡点清理：还原材料、还回空卡

### 装配驱动器
插入装配卡自动生产，共 9 条产线。装满即停。
- 左键/右键：升挡/降挡（挡位决定单轮产量：1/4/8/16/32/64/128/256/512/1024/1728/3456）
- Shift+左键：切换模式（连续生产 / 计划定量 / 补货维持）
- Shift+右键：设置计划数量或补货线
- 升级槽放超频核心：解锁满负荷挡（单轮不限量）
- 智能槽放智能核心：补货判定额外计入绑定频道的库存

### 超频核心
放入装配驱动器升级槽，解锁满负荷挡。

### 智能核心
放入装配驱动器智能槽。持频道配置器点击智能槽绑定频道。

### 装配监控器
总览同网络全部装配驱动器，总览/产线平铺两种视图。
- 远程调整挡位、模式、数量、命名，可暂停/恢复
- 支持搜索与高亮定位

## 三、链式传输

### 链式抓取器
沿设定方向逐个容器抓取物品进网络。黄绿粒子标示传输范围。
- 界面可设方向、距离（手持物品点击，数量即距离）、传输模式
- 默认每 5 秒工作一轮

### 链式推送器
按 3×3 模板把网络物品推送进沿线容器。

### 链式收发器
抓取与推送二合一，先抓后推。

### 链式模块（5 种）
插入链式机器底部模块槽（8 格），即插即用、拔出即复原：
- 距离模块：提升传输距离上限
- 容量模块：提升单次传输数量
- 模式模块：解锁传输模式（首槽/末槽/懒惰/清空/定量等）
- 原版容器模块：允许作用于箱子、漏斗等原版容器
- 多向模块：允许同时朝所有已选方向工作

### 网络收纳书
附到工具上后，击杀掉落与挖矿掉落直接进入你的网络。
- 合成：把书丢在地上，旁边丢一把未附魔的剑/镐/斧/锄/铲，雷击后合成
- 右键：切换模式（直进网络 / 先进背包）或绑定网络
- 潜影盒、束口袋等容器物品不会进网络，按原样掉落

## 四、元件工具

### 自动灌装机
把网络物品自动灌进储存容器，灌满即产出。支持潜影盒、存储元件、量子储存、网络抽屉。
- 清单区放要灌装的物品（9 格），容器区放空容器（9 格），成品从输出区取
- 网络有多少灌多少，不空等；可手动暂停

### 元件清理台
删除元件里不要的物品。
- 放入元件，Shift+点击某物品：该种物品全部删除
- 不可撤销，谨慎操作

### 元件转运机
存储元件与量子储存之间互转物品。
- 放入元件，点击物品转出为量子储存
- 切换模式可把量子储存转回元件；转入同档空量子储存，元件可存种类 +1
